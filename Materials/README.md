# Materials（持ち込み資料置き場）

このフォルダは、**オーナーが外部から持ち込む参考資料を入れる専用の置き場** です。
「どこにファイルを置けばいいか」で迷わないよう、**持ち込みデータはすべてここに入れてください**。

## 何を入れてよいか

種類は問いません。企画・作業の材料になるものは何でも入れてOKです。例:

- 画像（スクショ、写真、参考ビジュアル）
- モックアップ・図面・ラフスケッチ
- 参考資料（PDF、ドキュメント、既存の企画メモ）
- 表・データ（CSV など）
- その他、秘書に見てほしいファイル

整理したい場合は、`Materials/images/` のようにサブフォルダを自由に作って構いません。

## 秘書はここをどう使うか

- **企画フェーズで、秘書はまずこのフォルダの中身を確認**し、入っているファイルを企画の参考にします
- 資料があれば「この資料を拝見しました」と触れ、内容を踏まえて壁打ちを進めます
- 運用フェーズでも、関連する資料があればここを参照します

> このフォルダが空でも問題ありません。その場合、秘書は資料なしとして企画を進めます。
