# AI Secretary Template

**AI秘書を窓口にして、あらゆるプロジェクトを進めるための汎用テンプレート（原本）です。**

このテンプレートを複製して [Claude Code](https://claude.com/claude-code) で開くと、AIが「秘書」として起動し、キャラ設定 → オーナー情報のヒアリング → 企画（目的・やること）の壁打ちまでを案内します。以降は、秘書がタスクと作業履歴を管理し、「前回どこまでやって、次回何をやるか」を常に把握した状態で作業を続けられます。

ゲーム・執筆・リサーチ・事業運営・学習など、**プロジェクトの領域を問わず** 使えます。

---

## できること

- **AI秘書という窓口** … オーナーの指示を受け取り、判断・実行・報告まで一人の秘書が担う
- **履歴とタスクの自動管理** … 作業のたびに `History.md`／`Tasks.md` を更新し、中断しても次回スムーズに再開できる
- **量産の起点** … このテンプレートを複製するだけで、新しいプロジェクトを同じ枠組みで立ち上げられる

---

## 使い方

1. このテンプレートを複製する（GitHubの **Use this template**、または Releases のソースをダウンロード）
2. 複製したフォルダを **Claude Code** で開く
3. **`/Secretary` コマンドを実行する** … これが毎回の入口です。秘書が起動し、状態を見て初回オンボーディング／続きからの再開を自動判定します
4. 案内に沿って進める:
   - **オンボーディング** … ① 秘書キャラの決定 → ② オーナープロフィールのヒアリング
   - **企画** … このプロジェクトの目的・やることを対話で固め、`Concept.md` にまとめる
   - **運用** … 秘書が実行・進行管理を担い、`Tasks.md`／`History.md` を更新しながら進める

> **基本の使い方**: 作業を中断して後日戻ってきたときも、毎回 **`/Secretary`** から始めてください。前回どこまで進んだかを把握した状態で秘書が再開します。

初回は「秘書キャラを誰にするか」から聞かれます。こだわりが無ければ「おまかせ」で一般的なビジネス秘書として設定されます。

### 持ち込み資料がある場合

画像・モックアップ・図面・参考PDFなど、企画の材料にしたいファイルは **`Materials/` フォルダにまとめて入れておいてください**。企画フェーズで秘書がその中身を確認し、内容を踏まえて壁打ちを進めます。「どこに置けばいいか」で迷わずに済みます。

## ファイル構成

| パス | 役割 | 状態 |
|---|---|---|
| `.claude/commands/Secretary.md` | `/Secretary` コマンドの定義。毎回ここから秘書を起動する | 常設 |
| `CLAUDE.md` | Claude Code が最初に読む入口。全体の道案内 | 常設 |
| `Secretary/Secretary.md` | 秘書の振る舞い・進行管理ルール（キャラ非依存） | 常設 |
| `Materials/` | 持ち込み資料置き場。画像・モック・図面・メモ等を入れると、秘書が企画時に参照する | 常設 |
| `Templates/Concept_template.md` | 企画書の空雛形 | 常設 |
| `Secretary/Owner.md` | 秘書キャラ設定＋オーナープロフィール | オンボーディングで生成 |
| `Concept.md` | 企画（目的・やること） | 企画フェーズで生成 |
| `Secretary/Tasks.md` | TODO（これからやること） | 運用中に生成・更新 |
| `Secretary/History.md` | 作業履歴（最新を上に追記） | 運用中に生成・更新 |

---

## テンプレート表記の自動クリーンアップ

「これはテンプレートです」といった案内は最初だけ有用で、実運用に入ると残っていると紛らわしくなります。そこで、**企画が固まって運用フェーズに入る最初のタイミングで、秘書がテンプレート由来の案内を自動的に削除し、タイトルを実プロジェクト名に置き換えます**（`<!-- TEMPLATE-ONLY -->` マーカーで囲まれた箇所）。一度だけ実行され、それ以降は綺麗な状態で運用できます。
